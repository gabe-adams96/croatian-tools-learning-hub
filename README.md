## Overview

Croatian Tools is a compact learning resource built to help users drill Croatian with interactive practice. Because it is delivered as a static web app, it can be opened in any browser and distributed without extra infrastructure or a complicated install path.

This release is centered on nominative plural practice. That makes it a practical option for learners who want repeated work on one grammar topic, whether they are studying on their own, supporting classroom work, or doing a fast review online.

## Installation

Clone the repository and open the project folder locally:

```bash
git clone https://github.com/gabe-adams96/croatian-tools-learning-hub.git
cd croatian_tools
```

To check it during development, serve the directory with any static server and open the generated address in your browser. With a basic local server, start it from the project directory and visit the URL it prints.

For deployment, publish the built or source static files to GitHub Pages.

## Usage

Launch the site in your browser and start working through the Croatian exercises that are available.

Typical workflow:
1. Open the static site locally or through GitHub Pages.
2. Pick the practice area you want to study.
3. Work through the nominative plural drills.
4. Reload or return to the page whenever you want a fresh practice session.

For local changes, run a static server, edit the files, and refresh the browser to confirm the updates.

## Configuration

Since this project is a static web app, the main settings live in the site files rather than in a separate configuration backend.

To modify content or exercises, edit the relevant JavaScript and page assets in the repository. When setting up deployment, point GitHub Pages to the static site output or the repository root, depending on your chosen structure.

Example project layout:


## FAQ

**How do I run it locally?**  
Clone the repository, serve the folder with a static server, and open the local URL in your browser.

**How is it updated?**  
Updates happen by editing the static site files and republishing the project, including GitHub Pages when that is the hosting option.

**Where do I change the exercises?**  
Update the JavaScript and page files that define the practice content, then adjust the relevant sections there.

**What if the page does not load correctly?**  
Make sure the files are being served from a static server, confirm that JavaScript is enabled in the browser, and check that the GitHub Pages path matches the deployment layout.
